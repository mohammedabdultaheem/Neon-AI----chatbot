# 🚀 NEON AI - Futuristic Chatbot

NEON AI is a high-performance, real-time AI chatbot with a stunning **Futuristic Glassmorphism UI**. It leverages the power of **Google Gemini AI** to provide intelligent, context-aware responses through a seamless WebSocket connection.

![NEON AI Preview](https://via.placeholder.com/800x400/000000/00FFFF?text=NEON+AI+FUTURISTIC+INTERFACE)

## ✨ Key Features

- **Futuristic UI**: Beautiful dark-mode interface with glassmorphism, neon gradients, and interactive particle backgrounds.
- **Neural Login System**: Secure entry point with an immersive cyberpunk-style access terminal.
- **Real-time Streaming**: Instant AI responses using WebSockets for a natural conversation flow.
- **Gemini Integration**: Powered by Google's latest Gemini Flash models.
- **Protected Routes**: Secure navigation management using React Router.
- **Responsive Design**: Optimized for a premium experience across all screen sizes.

## 🛠️ Tech Stack

### Frontend
- **React 19**
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **React Router Dom** (Navigation)

### Backend
- **FastAPI** (Python Web Framework)
- **WebSockets** (Real-time communication)
- **Google Generative AI SDK**
- **Python-dotenv** (Environment Management)

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.10+
- Node.js 18+
- A Google Gemini API Key

### 2. Environment Setup
Create a `.env` file in the `backend/` directory:
```env
GEMINI_API_KEY=your_api_key_here
```

### 3. Installation & Running

#### **Backend**
```bash
cd backend
pip install -r requirements.txt
python main.py
```

#### **Frontend**
```bash
cd frontend
npm install
npm run dev
```

## 🔒 Security
Sensitive information such as API keys are managed via environment variables and are excluded from version control via `.gitignore`.
